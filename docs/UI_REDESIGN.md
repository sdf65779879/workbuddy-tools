# WorkBuddy 界面与用量统计更新

所有六个工作区使用统一的薄荷绿、浅蓝渐变背景、半透明白色卡片、圆角导航和绿色主操作。支持浅色 / 深色外观、桌面与窄屏布局。桌面窗口默认 1280 × 860。

品牌名称为「WorkBuddy 鑫杭加速」，深色外观入口名为「伪神模式」。顶部实际积分额度在启动后自动同步，可手动刷新，展示所有托管账号的实际剩余、总额、已用与同步时间；不限量账号独立计数，读取失败显示错误。账号状态依照轮转启用、暂停、冷却、有效期和积分保底判断就绪。

国内个人额度通过 codebuddy.cn 的 get-user-resource 接口读取，国际账号使用 workbuddy.ai 对应接口，企业账号使用企业用量接口。使用明确字段解析周期包和固定包，完成分页后累加剩余/总额/已用，不使用遍历猜字段或本地常量。精确余额与用于路由的整数权重分开，内部不限量权重不会作为实际额度输出。

## 用量统计

原「概览」现在为「用量统计」，默认打开此页。

- 时间：今日、近 7 天、近 30 天、全部历史和自定义日期；按北京时间 UTC+8 展示。
- 筛选：账号、模型，所有历史汇总与明细使用相同筛选范围。
- 指标：请求尝试数、失败数、输入 / 输出 / 总 Token、成功率、平均耗时、记录积分。
- 图表：输入 / 输出 Token 与成功 / 失败请求趋势，可切换为数据表；Token 构成比例。
- 运行指标：最近 60 秒 RPM / TPM、所选范围平均首字延迟、生成速度及可观测缓存命中率。
- 明细：按模型 / 账号统计、排序、分页和 CSV 导出；最近请求与完整日志入口。
- 每 15 秒自动刷新，可关闭。无记录或读取失败会显示对应状态。

统计存储延续原来的 usage.json 小时桶格式并兼容旧记录。新字段从新请求开始采集，历史上没有记录的缓存、首字延迟或 Token 数据无法追溯补齐。单个请求多次轮转重试会记录多个上游尝试，因此用量页的尝试次数与日志页的客户端请求次数可能不同。实时 RPM / TPM 按当前进程最近 60 秒完成的上游尝试计算，独立于历史日期筛选，同时保留账号 / 模型筛选。

## 其他页面

- 账号保险柜：三列账号卡，真实积分、Token 剩余有效期、请求状态；搜索、导入、改名、启用、暂停、签到、保活、任务、分享摘要、持久化删除与切换。
- 运维：全号签到、积分刷新、Refresh Token 续期，逐号报告成功和失败。
- 自动化：应用运行期间按配置时间每日签到；打开后台保活后每 6 小时续期；切换页面不停止。程序关闭后不执行。
- 成长任务：接受任务、领取已达标奖励、同步进度、筛选待领；行为类任务进度来自实际使用。
- 网关：启停、实际连接测试、主密钥生成和保存、轮转状态与真实累计统计；高级设置包括端口、轮转策略、模型映射与 API Keys。
- 分享与日志：本机接口复制、分享文案、请求筛选和展开详情、日志归档信息。

## 二维图标

图标通过内置 imagegen 工具逐枚生成，使用透明 PNG，原文件保留于 public/icons/：usage、vault、checkin、growth、gateway、share、credits。导航、指标和行动卡复用此套素材。

完整提示词、生成方式与日期见 public/icons/imagegen-prompts.json。公共组件为 src/components/AppIcon.tsx。

## 启动与验证

```powershell
npm run tauri:dev
```

项目为 Tauri 桌面应用，真实配置、用量和操作通过 Rust 命令调用。直接运行 Vite 浏览器预览时没有 Tauri 后端。

```powershell
npm run typecheck
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri:build
```

output/playwright/setup-preview.js 仅供浏览器验收，注入明确的虚构测试数据；不会被生产代码导入，也不会读取本机账号凭证。截图目录 output/playwright/。
